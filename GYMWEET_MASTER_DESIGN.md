# GYMWEET CORE — MASTER DESIGN

## 1. ZÁKLADNÍ SMĚR
GYMWEET musí působit čistě, moderně, prémiově a jednoduše.

Hlavní principy:
- světlý, velmi čistý základ
- hodně bílého prostoru
- černá / antracitová pro hlavní prvky
- mintová zelená jako hlavní akcent
- velké výrazné nadpisy
- jednoduché a přehledné rozložení
- jemné stíny
- zaoblené karty
- minimalistické lineární ikony
- žádné zbytečné barevné kombinace

---

## 2. BAREVNÝ SYSTÉM
### Hlavní barvy
- Background: bílá / téměř bílá
- Primary text: černá / velmi tmavá antracitová
- Secondary text: tmavší šedá
- Borders: velmi světlá šedá
- Accent: mintová zelená
- Selected state: mint border + mint icon / check
- Primary CTA: černé tlačítko + bílý text

Mint se používá střídmě:
- aktivní stav
- progress
- check
- graf
- zvýraznění důležité pozitivní informace
- aktivní ikona / položka

---

## 3. TYPOGRAFIE
- moderní sans-serif
- velké a výrazné hlavní nadpisy
- vysoká čitelnost
- omezený počet velikostí
- jasná hierarchie

Hierarchie:
1. hlavní headline
2. subtitle
3. card title
4. body text
5. helper text / poznámka

Logo GYMWEET:
- uppercase
- výrazný spacing mezi písmeny
- čistý sportovní / technologický vzhled

Tagline:
"Chytrý trénink. Skutečné výsledky."

---

## 4. KARTY
Karty:
- bílé nebo velmi jemně tónované
- lehký border
- jemný shadow
- větší radius
- dostatek vnitřního prostoru

Vybraná karta:
- mintový border
- případně jemný mint tint
- mint check / radio state

---

## 5. TLAČÍTKA
### Primary button
- černé / téměř černé pozadí
- bílý text
- velká výška
- zaoblené rohy
- přes téměř celou šířku
- může obsahovat mintovou šipku vpravo

### Secondary button
- bílé pozadí
- tmavý border
- tmavý text

### Text action
- mintový text
- používá se např. pro:
  - Přihlásit se
  - Registrovat se
  - Zpět

---

## 6. INPUTY
Input fields:
- bílé pozadí
- světlý border
- velká výška
- velký radius
- ikona vlevo
- případná akce vpravo
- placeholder tmavší šedou

Příklad:
- E-mail
- Heslo
- Potvrď heslo

---

## 7. IKONY
- jednoduché line icons
- černé / antracitové
- aktivní nebo pozitivní stav v mint
- ikony mají být konzistentní napříč aplikací

---

## 8. PROGRESS
Onboarding progress:
- segmentovaný progress bar
- hotové segmenty = mint
- nehotové = světle šedé
- text např. "Profil 3/5"

---

## 12. UX PRINCIPY
GYMWEET má být:
- jednoduchý na pochopení
- bez zbytečného přemýšlení
- každá obrazovka má mít jeden hlavní úkol
- důležité CTA vždy jasně viditelné
- vizuálně klidný
- konzistentní
- mobilní design jako hlavní priorita

---

## 13. CO JE UZAMČENÉ
Uzamčený je:
- vizuální styl
- světlý základ
- černá + bílá + mint
- styl karet
- styl tlačítek
- styl inputů
- typografická hierarchie
- styl progressu
- celkový clean / premium feeling

---
